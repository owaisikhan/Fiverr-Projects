# Deliveries

Every folder here is the code of one Fiverr order, copied from the client
repository the owner hands over (see "Adding a delivery" in `AGENTS.md`). Its
entry on the site lives in `app/_data/deliveries.json`, written in the same
commit.

These folders are not part of the portfolio build: ESLint and Tailwind both
ignore this directory, and nothing in `app/` imports from it.
